This separately named interface runs actual MAPLE reduced wind records and
actual SYRUP positive water events on one evolving Native windowed bed. It is
Source-only work. No test, transport, provider/runtime image, memory fit or
calibration is qualified by this document. The original Dense implementation
and all67 baseline MASY Source files remain unchanged.

The Native855 completed-record receiver is locally committed ascbcb7ac on3af;
its genuine actual CPU qualification is still Root-pending. The factory first
runs the original process/headroom check, imports Native lazily, then checks the
actual WindowedWindRecord class and plain method signature before any private
copy or transport. Older Native without this API still refuses. Only a fresh
coherent Source/runtime pair and Root acceptance of the affected Native case
may admit execution; this Source connection grants no model acceptance.

The adapter calls completed_owner.reservoir_arithmetic_scale_kg() once, with no
