# Small windowed CPU alternation

This separately named interface runs actual MAPLE reduced wind records and
actual SYRUP positive water events on one evolving Native windowed bed. It is
qualified for the bounded synthetic CPU interface case recorded below. The
four-event trajectory and its prerequisite checks passed on the exact locked
sources; larger domains, GPU and production calibration remain separate. The original Dense implementation
and all67 baseline MASY Source files remain unchanged.

coherent Source/runtime pair and Root acceptance of the affected Native case
may admit execution. The accepted pairing and actual execution below establish
only the stated bounded profile.

refusal remains a refusal; no water event is silently skipped.

`build_windowed_bed(physical=..., context=..., limits=...)` receives an actual

Private ordinary constructors refuse. Unknown backend/shape/storage/context
and incompatible or nonempty wind/water states refuse.
