# Directory currentness checks

This Source change is based on private MASY a9d6643, MAPLE fa2d5ef and SYRUP603f8ae. It changes only the opener used by C's private _same_directory. Initial held-parent acquisition and every direct dense_original_inputs._open_dir caller retain the original component walker.

On Linux x86_64 LP64, an eligible absolute path is resolved afresh with openat2(RESOLVE_NO_SYMLINKS). This covers every component and magic links. A root-directory READ reservation is held during that call; the resulting final directory is READ-opened with CLOEXEC. The original two fstats, dev/ino comparison and result-close remain unchanged. Relative, root-only, double-root, parent-traversal, NUL, overlong or unsupported-profile paths use the original walker. The4095-byte value selects the optimization; it is not a new original-path acceptance cap.

There is one deliberate permission difference: non-root intermediate ancestors need search permission during a successful fast currentness check, rather than the original walker's READ permission at each component. A directory changed to search-only can therefore remain current. Root READ and final-directory READ remain required. This is not identical old refusal behavior. Initial acquisition still refuses that search-only intermediate through the original walker.

For D>=1 non-root components, root reservation plus result retain the original two-transient-fd requirement, including a one-free-slot EMFILE refusal. Successful calls use two opens and closes, saving D-1 of each. Root-only resolution keeps the original one-fd walker. Failed optimization may add work; no speed or fit is promised.

Only a fully successful private ABI binding is retained. Setup borrows the existing pythonapi library handle through a private CDLL facade with use_errno=False. No path, descriptor, identity, hash, kernel support, errno or failure is cached. Ordinary setup/reservation failure and negative raw syscall results delegate to a fresh original walker outside caught contexts. Exceptions raised by the call/body propagate after known-fd cleanup. Each owned fd slot is cleared before its close; multiple actual primary/cleanup failures are preserved in a BaseExceptionGroup. No complete asynchronous ownership or race equivalence is claimed.

The new test module separates mocked dispatch from genuine filesystem controls. Genuine tests require Root's original bounded supervisor and supported non-root credentials/kernel. An unmet positive fails explicitly; it is never skipped or simulated. They cover x-only ancestors, final READ, actual error parity, inode/file drift, CLOEXEC, observed two-fd peak, real one/two-slot pressure and actual fd0 ownership. Descriptor pressure stays within the existing1024 cap; stdin is restored with its original inheritability.

No tests or syscalls were executed during Source authoring. Before any publication, Root must independently accept the Source, execute the filesystem controls and prepare an honest new Source/runtime/compiled identity, then separately qualify the genuine first active publication. All original Native/hash/environment/process guards and caps remain. There is no new executor, heap-fit claim, Native physics change or model acceptance.
