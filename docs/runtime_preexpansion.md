# Compiled-identity pre-expansion eligibility

Both the ordinary CPU runtime collector and the private operation-scoped collector admit their metadata before sorting module names, calling a holder's original `__file__` getter, normalizing roots, or decoding/splitting maps. This changes metadata eligibility; it changes no Native physics, output identity schema, file hashing, alias limit, reuse success conditions, or existing final file/byte limits.

The source population is `7m + 8e + 23v + 3r + k + r*v <= 100000`: `m` module occurrences, `e` actual extension matches (aliases included), `v` all decoded maps rows, `r` raw library roots, and `k` bounded MRO/proxy/typing-binding roles. The extra five module roles retain admitted holder/file pairs and dictionary slots. The same bounded raw maps buffer is subsequently parsed by the existing parser. Eleven `bytes.count` calls plus one `endswith` account for every UTF-8 `str.splitlines` delimiter and CRLF, before decoding. The existing 8 MiB read bound and missing-maps behavior remain.

Inputs must be a plain module dictionary with plain string names (at most 1024 characters), and a plain root list with plain string paths (at most 4096 characters). Instance `__file__` is an exact string of at most 4096 characters or `None`. Genuine module subclasses with the original `ModuleType.__getattribute__` are supported, with no class-level file descriptor. An absent file cannot use a module `__getattr__` fallback. Exact ordinary type holders with no file throughout their MRO are supported. Other holders, custom getters/metaclasses, descriptors, foreign keys and non-string file values refuse without calling their hooks or representing their values.

The only custom-metaclass exception is genuine `typing.io` and `typing.re` in the selected CPython 3.12.3 Source. Their pinned `typing.py` Source, exact metaclass/getter code, closure, globals, builtins and `super` binding are checked; their complete class MRO must have no file. The approved branch cannot enter the warning path. A compile-only declaration with the genuine `import warnings` compiler context proves the exact code without constructing a substitute class. A different typing Source is unsupported for this exception.

Namespace dictionaries and proxies are streamed without copying/sorting or calling foreign keys. Each has at most 100000 keys and exact plain string keys of at most 1024 characters; this is a separate finite control-work domain, not an eager namespace materialization bank. Unknowns refuse. Existing earlier `dict(sys.modules)` copies and `site.getsitepackages()` list construction remain their real positive owners; this guard does not claim to precede them.

Admitted holder/file references remain live until collection finishes. Immediately before the one original getter call, dictionary cardinality and holder identity are checked; its result must be the exact admitted file reference. Length changes during streaming refuse with a fixed error. This is an owned quiescent-worker interval, not an atomic snapshot or a defense against hostile concurrent same-size dictionary mutation. Reuse images bind the new helper code, constants, typing closure, genuine descriptors and operators. Failures still discard a pending reuse scan.

The private projection adds positive current/next admission banks, raw buffers, proxies, counters, error text, constructor temporaries, fixed Source code and all helper frames. It is a logical metadata projection under the selected ordinary CPython construction contract, not an allocator, kernel-service, heap-peak, timing or fit guarantee. The original seventeen external resource terms and all existing process/cap contracts remain unchanged. Root must qualify the new MASY Source/runtime and affected pure checks; no old runtime receipt is relabelled.
