# Original-input pack prerequisite

This opt-in component captures a NEW default Dense NumPy runner's original typed
inputs and decodes them without constructing a bed or runner. It is stage A only:
there is no event/HEAD store, runner restore, active-event, production, windowed or
GPU restart. Current sediment must later come from the actual native exact codec.
Original inventory is an audit vector; retained native genesis state validates it
in a later stage. Prescribed vegetation and existing native dry-reset laws do not change.

The isolated prototype uses complete immutable scoped MASY1703 plus accepted22,
MAPLE39 plus native15 and SYRUPd05 sources. It is not a genuine source-locked pair
qualification. Native15 publication and a fresh whole committed-pair gate remain.

The finite registry and exact scalar/array encoding preserve declared and instance
fields, None, tuple/list and shared context/config anchors. Native fixed-ksat,
Plot1-default, quantile-bin and resolved-rainfall factories validate every resolved
field. Unsupported recipes/types/profile refuse rather than being normalized.

Use these APIs from the already verified locked CPU process:

```python
pack = capture_original_inputs(new_runner, source_identity=verified_source_refs)
manifest_sha = save_original_inputs(new_path, pack)
decoded = load_original_inputs(
    new_path,
    expected_manifest_sha256=manifest_sha,
    expected_source_identity=verified_source_refs,
)
```

`verified_source_refs` is the closed mapping `{kind, masy, maple, syrup}`. The three
source references are SHA256 identities supplied by the independently verified
runtime; this version accepts only `kind="source_manifest_prototype"`. It refuses
a genuine-runtime label; a later integration must establish and qualify that
separate path. This component checks exact binding, not source
qualification or authenticity. Retain the actual source/runtime objects separately
using existing provenance tools. A new process must verify that original runtime
before using decoded inputs; no automatic upgrade or relocation is performed.

The returned carrier contains the typed22 original capsule and complete original
initialization receipt, native wind config and empty initial pool, native water
inputs and initial soil, controls/limits, schedule/hash, initial inventory and
controlling/static records. Original prescribed cover is an audit input, not a
second current vegetation authority. Later physical restore must exact-check and
bind the native prescribed vegetation. The exact initial inventory is preserved;
this stage cannot establish its physical origin without the retained genesis
native checkpoint and does not claim to do so.
Inventory audit bytes, including a native negative zero if present, stay exact;
this adds no sediment sign policy. The existing native soil-water entry policy
separately refuses negative zero and remains unchanged.

Capture reads an already initialized NEW default runner at cursor/count0 with empty
receipts/routing/active evidence and exact original epoch, identities and zero
totals. It performs no transport, rainfall, deposition, reset, commit or finalizer.
It retains native input/array references and never copies or changes their flags.
The caller must keep those aliases quiescent through capture/save. Save rehashes
them and independently checks actual written NPY header/data before sealing.
Python typing/hash binding is not protection from reflection or an untrusted
same-user writer. No fd-based scheme authenticates arbitrary Python history.

Decode creates new private NumPy arrays and freezes them. Geometry/classes/commit/
avalanche/context/availability named anchors are decoded once and reused by native
context/config. All native declared AND instance fields, scalar kinds/float bits,
None and list/tuple distinctions are closed. Only code-owned literal type tags are
accepted; no payload import, pickle, registration hook or generic class decoder.
Original dictionary insertion order is preserved, including native configuration
maps and original metadata. Static records must match recomputed native records
in exact type/value/order. The separate caller source-reference mapping binds
closed string identities independent of its insertion order.
Native fixed-ksat, empty-override Plot1, hop-quantile and resolved-rainfall factories
must reproduce every saved raw resolved field exactly. A rainfall authoring mask
is already folded into RainfallField.multiplier; its explicit resolved validation
recipe uses `rainfall_field(ny,nx,scale=multiplier,active_mask=None,xp=np)` and never
invents a missing authoring mask. Inactive/masked zeros and signed bits survive.
The first profile requires the same geometry, grain classes, commit spec,
avalanche spec and availability array objects in the original context/config.
Equivalent but distinct availability arrays refuse; no implicit rebinding occurs.
Scalar availability anchors are unsupported. Capture checks original committed
terrain against the actual initial native committed state. Native static graph
construction validates the original terrain through SYRUP's checked API; this
temporary graph supplies no retained routing state or event/reroute receipt.

Default engineering ceilings are64 cells,6 classes,16 voxels/column,16000 flat
cohorts,8 events,64 hop bins and64 rainfall intervals/event. Numerical payloads are
at most64MiB and256 files; all serialized files together at most72MiB; metadata
at most4MiB with100000 nodes and depth24, and NPY headers at most4096 bytes. Limits
may tighten these ceilings. Factory dimensions are checked before native allocation.
The wire uses a bounded flat typed-node table so tagging does not inflate JSON
nesting beyond the cap; native value traversal also has depth/count bounds.
Arrays must be contiguous fixed numeric/bool types of rank<=4. Raw/expanded counts,
shape products and aggregate sizes pass before first payload hash/header/expansion.
Every numeric file must be referenced by the closed typed graph. Raw aggregate
bytes count an exact manifest.json/manifest.tmp hardlink pair once; entry count
still includes both names, and every other foreign hardlink refuses.
The raw NPY header-length prefix passes the header cap before NumPy may read or
parse that header; its normal parser then checks the native header contract.
Conservative metadata charges pass before creating an oversized JSON encoding.
File access follows no symlink at any path component, uses opened descriptors,
refuses FIFOs/nonregular files/foreign hardlinks and rechecks fd/name identity.
No compression/archive parser or unrestricted np.load is used.

Save requires a new exclusive directory on caller-declared local POSIX storage
supporting no-follow directory opens, hardlink seal and file/directory fsync. It
checks conservative space/inode headroom before creating it. A successful fsync
call is not a physical durability proof; the storage contract remains explicit.
Files become readonly before sealing. Manifest publication uses a no-clobber
hardlink, never an unproved directory rename. Existing paths are never overwritten.
Actual full-file identities and manifest bytes are read back before seal linking.
A preseal failure retains an unsealed directory that load refuses. Choose a new
attempt name; cleanup/recovery is an explicit operator operation outside this API.
From immediately before seal-link invocation, an ordinary failure raises
OriginalPackPublicationUncertain; asynchronous interrupts keep their type with an
uncertainty note. No event acceptance is implied. An exact leftover manifest.tmp
hardlink to manifest.json is read-only recoverable and is not deleted by load;
foreign/partial leftovers refuse. A later outer store must reconfirm durability
before accepting a boundary. No HEAD, retries, event receipts or GC are implemented.
Async-interrupt descriptor hygiene is best effort; the bounded worker exits and
the OS closes its descriptors. Interrupt type and possible publication remain
truthful. No claim covers a hostile writer with the same user identity.

Qualification is bounded CPU component evidence only. The task-owned launcher uses
the existing MAPLE venv, `-I -B`, immutable complete source origins/genuine source-built
metadata, hidden GPUs/JAX CPU, AS8GiB, CPU90/120s, per-file96MiB, core0 and wall180s.
Resident memory and exact reference file/data/serialized counts are recorded in
task receipts. Data caps are not peak-RSS or large/GPU/windowed readiness claims.
