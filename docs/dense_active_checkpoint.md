# Private default CPU water export and cold continuation

This StageA component composes the independently Source-reviewed six-path
implementation with private MASY13496d1, MAPLEfa2 and SYRUP603. It awaits
Root changed-source runtime and numerical qualification. Historical
in-memory and codec qualifications retain their exact original scopes.

The separate original-input ownership correction is inherited from
MASY13496d1. It preserves the fromfile allocation while supplying the
readonly owning terrain arrays required by the unchanged Native603
anchor. Its actual CPU qualification is a separate prerequisite; Source
composition alone does not establish provider support or cold restart.

The private API borrows an actual accepted static C parent, advances a real
water event to an unfinished original Native boundary, exports it through
Native SYRUP SAVE, audits the child against the retained original writer using
Native P2, and later loads that child in a new borrowed runner. Native603 owns
the bit-exact static-terrain anchor comparison. The new module issues a local
cold entry witness and opaque token only after Native validation, semantic
comparison, accepted-root disjointness, source checks and capsule admission.
`resume_water` then invokes the original Native continuation and acceptance
tail. Genuine native ready-dry completion still wins over a requested pause.

```python
with borrow_water_parent(handle, expected_parent=actual_parent_token) as parent:
    runner = parent.take_runner()
    token = pause_water(runner, runtime_reference=actual_runtime, boundary_ordinal=1)
    export_sha = export_water_pause(parent, runner, token, attempt=new_sibling_path)
```

In a separately admitted reader process, reopen the same C parent, borrow its
actual prepared runner, and call `load_water_pause(parent, runner,
attempt=retained_sibling_path, expected_export_sha256=actual_writer_sha,
runtime_reference=actual_runtime)`. The returned token is local, single-use and
bound to that runner/PID/thread. The caller supplies actual externally retained
writer metadata. There is no JSON authority boolean, portable Python token,
fake DenseStage/Native BedCommit, fresh event entry, replay or reset on LOAD.
The old warm `_entry_digest` and the ordinary CPU/device/production engine
remain unchanged through exact warm fallbacks.

Each attempt contains `entry/capsule.json`, the exact three Native files under
`native/`, and `export.json`. The capsule preserves original entry inventory,
stage stamp/identity, rainfall plan and schedule/provenance, entry-routing
relations, source/environment, accepted C parent and logical operation. Floats
use canonical hex, retaining signed zero. A portable Native semantic digest
covers actual Native wire fields and every primary physical bed field, without
serializing object IDs, modules, graph caches or process-local mutation seals.
Native SAVE identity binds the capsule's whole hash. Native P2 must audit the
original retained writer; a loaded substitute is never used as the writer.

The artifact is retained-local: raw child custody includes its device/inode and
directory metadata. Moving or copying a native child is unsupported. The
attempt must be canonical, owned and outside the C root. Export uses exclusive
new paths and retains failed attempts. It rechecks inputs on failure; unchanged
input leaves the warm token unconsumed, while detected mutation halts private
work without replacing the original failure. Context close refuses active
busy/finishing/exporting work before releasing the parent guard; an idle paused
lease is explicitly abandoned on close. After transfer the parent keeps only a
weak runner reference. A cold runner must remain inside its live parent borrow.

The original pause limits, runtime-family guards and reservation remain in
force. Additional Source-visible owners are admitted before relevant work:
capsule/JSON buffers and parsed values, schedule vectors and inventory, Native
P1's actual serialization increment, snapshot/decoder copies, D4 graph factory
and integrity-rebuild outputs/scratch, and streamed hash buffers. The reader
admits raw metadata sizes before reading/parsing and actual archive headers
before array materialization. It narrows the child to one wet state and bounds
both archives together by8MiB, JSON by2MiB and each wrapper document by1MiB.
The reader accounts for complete admitted U and simultaneous terrain/decoded
owners; a2T-only estimate is insufficient. Exact role/call formulas and error
overlaps are in the task's resource ledger. These are requested-payload/metadata
bounds, not proof of total heap/JIT/RSS fit. Root must independently apply the
existing whole-worker AS/CPU/wall/output/disk/inode/headroom gate. No cap is
raised to admit a larger case. Export also reserves complete sibling disk/inodes
plus C's fixed1GiB/256-inode free reserve before creation.

The Source-authored first test uses genuine C originals/genesis, warm pause,
Native SAVE/P2, a new real parent borrow, Native anchored LOAD and dry resume,
compared with actual uninterrupted Native results and complete accepted state.
Its Native-result oracle excludes only the existing five runtime timers. Root
must separately sequence the fresh writer, verify it is fully reaped, pin its
readonly expectation, then launch a fresh reader through the existing bounded
engine. Native pytest never spawns another Native interpreter. Source method
counts are predictions until actual Root collection/freeze/check.

This component publishes no active C HEAD, revision, acknowledgment or accepted
event. C still names the old accepted boundary. Crash recovery can recover that
boundary, but active-envelope durable exactly-once semantics and lost-ACK
recovery remain StageB work. Wind-active, dynamic vegetation, production,
windowed, GPU, source migration and portable bundle relocation are excluded.
